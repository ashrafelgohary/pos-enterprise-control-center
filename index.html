The story

Problem → Solution

Updating VISA payment configuration on store POS terminals used to be a manual, terminal-by-terminal job.

The manual way

  • Connect to each POS individually and edit the XML by hand
  • Fix file ownership and permissions manually on every terminal
  • Easy to push the wrong file to the wrong terminal
  • No central record of what was deployed, where, and by whom
  • Stores informed ad hoc — or not at all

With POS Enterprise Control Center

  • Upload all XML files at once through a web interface
  • Files matched to terminals automatically by MAC address
  • Everything validated before a single file is pushed
  • Ansible updates many terminals in parallel, with live status
  • Full history, audit trail and a ready-to-send store email
